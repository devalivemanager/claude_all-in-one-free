# 007_attendance_cli — ERP 인사 근태 집계 CLI

출퇴근 기록 CSV 파일을 읽어 사원별 근무일수, 총근무, 연장·야간·휴일 근무시간, 지각 횟수를 표로 집계하는 Rust 커맨드라인 샘플입니다.
ERP 인사 모듈의 근태 마감 기능을 아주 작게 줄인 교육용 예제입니다.

> **주의: 교육용 단순화 규칙입니다.** 실제 근로기준법, 회사별 취업규칙, 유연근무·교대제, 공휴일, 수당 배율 등은 반영하지 않았습니다. 실무에 그대로 쓰면 안 됩니다.

## 기술 스택

- Rust 1.97 (edition 2021)
- 표준 라이브러리만 사용 (외부 크레이트 없음, 날짜·요일 계산도 직접 구현)
- 테스트: `cargo test`, 정적 검사: `cargo clippy`

## 폴더 구조

```
007_attendance_cli/
├── Cargo.toml
├── Cargo.lock
├── .gitignore          # target/ 제외
├── README.md
├── data/
│   └── sample.csv      # 예시 입력 (사원 3명, 2026-10-26(월) ~ 11-01(일))
└── src/
    ├── main.rs         # CLI 진입점, 파일 읽기·행 단위 집계·경고 출력
    ├── record.rs       # CSV 행 파싱 (날짜·시각 검증, 요일 계산)
    ├── calc.rs         # 하루치 근무시간 계산 규칙
    └── report.rs       # 사원별 누적과 표 출력
```

## 실행 방법

```bash
cd 000_sample_project/007_attendance_cli
cargo run -- data/sample.csv
```

출력 예시 (경고는 표준 에러, 표는 표준 출력으로 나갑니다):

```
경고: 19번째 줄을 건너뜁니다 - 시각 형식이 잘못되었습니다: '25:00'
경고: 20번째 줄을 건너뜁니다 - 열 개수가 4개가 아닙니다 (3개)
경고: 21번째 줄을 건너뜁니다 - 날짜 형식이 잘못되었습니다: '2026-02-30'
경고: 22번째 줄을 건너뜁니다 - 중복 기록입니다 (E003 2026-10-29)

근태 집계 결과 (시간 표기는 시간:분)

사번  근무일수  총근무  연장   야간  휴일  지각
-----------------------------------------------
E001       6일   52:47  8:17   1:30  4:30   1회
E002       6일   45:25  0:00  28:00  5:30   5회
E003       4일   26:30  0:00   0:00  0:00   1회

사원 3명, 경고 4건
```

종료 코드: 정상 0, 파일을 읽지 못하면 1, 인자가 잘못되면 2.

## 테스트 방법

```bash
cargo test                    # 단위 테스트 29개
cargo clippy -- -D warnings   # 경고 없음 확인
```

테스트 범위:

- `record.rs`: 정상 파싱, 열 개수 오류, 빈 사번, 잘못된 날짜(2월 30일, 13월 등), 윤년, 잘못된 시각(24:00, 08:60 등), 출퇴근 동일, 요일 계산
- `calc.rs`: 휴게시간 경계값(3:59/4:00/7:59/8:00), 연장 경계값(8:00/8:01), 지각 경계값(08:59/09:00/09:01), 야간 경계값(22:00/22:01 퇴근, 새벽 출근), 자정 넘김, 자정 정각 퇴근, 주말 휴일근무(10시간 근무도 연장 0), 다음 날 저녁 22시를 넘긴 야간, 금요일 밤→토요일 새벽
- `report.rs`: 시간 표기, 누적, 표 정렬
- `main.rs`: 헤더·주석·빈 줄 건너뛰기, 잘못된 행의 줄 번호 경고, 중복 기록, 샘플 파일 전체 집계

## 입력 형식

```
사번,날짜,출근시각,퇴근시각
E001,2026-10-26,08:55,18:00
```

- 첫 줄이 `사번`으로 시작하면 헤더로 보고 건너뜁니다.
- 빈 줄과 `#`으로 시작하는 줄은 주석으로 건너뜁니다.
- 날짜: `YYYY-MM-DD` (실제로 존재하는 날짜만 허용)
- 시각: `HH:MM` 또는 `H:MM`, 00:00 ~ 23:59
- 따옴표로 감싼 필드 등 복잡한 CSV 문법은 지원하지 않습니다(쉼표로 단순 분리).

### 잘못된 행 처리

다음 경우에는 `경고: N번째 줄을 건너뜁니다 - 사유` 를 출력하고 그 행만 건너뜁니다.

- 열이 4개가 아님, 사번이 비어 있음
- 날짜·시각 형식 오류
- 출근시각과 퇴근시각이 같음
- 같은 사원·같은 날짜의 기록이 이미 있음(중복, 먼저 나온 행만 인정)

## 계산 규칙 (교육용 단순화)

모든 계산은 분 단위 정수로 합니다.

| 항목 | 규칙 |
|------|------|
| 자정 넘김 | 퇴근시각이 출근시각보다 이르면 다음 날 퇴근으로 봅니다 (예: 22:00 → 07:00 = 9시간). 최대 23시간 59분 |
| 체류시간 | 퇴근 - 출근 |
| 휴게시간 공제 | 체류 4시간 이상이면 30분, 8시간 이상이면 1시간 공제 |
| 총근무 | 체류시간 - 휴게시간 |
| 연장근무 | 평일 총근무 중 8시간 초과분 |
| 야간근무 | 출근~퇴근 중 22:00~06:00에 걸친 시간 (휴게 공제 없이 그대로 셈, 요일 무관) |
| 휴일근무 | 출근일이 토·일이면 그날 총근무 전체. 휴일에는 연장·지각을 따로 세지 않음 |
| 지각 | 평일에 09:00을 넘겨 출근(09:00 정각은 정상, 09:01부터 지각) |
| 근무일수 | 유효한 기록이 있는 날의 수 |

단순화로 인한 특징:

- 요일은 **출근일 기준**입니다. 금요일 밤에 출근해 토요일 새벽에 퇴근하면 평일 근무로 봅니다.
- 지각 기준이 모든 사원에게 09:00으로 고정이라, 오후 출근·야간 교대 근무자도 지각으로 집계됩니다(샘플의 E002).
- 공휴일, 휴게시간의 실제 위치, 연장·야간·휴일의 중복 가산은 다루지 않습니다.
