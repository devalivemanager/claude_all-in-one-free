# 004_web_game — 야근 탈출

퇴근하고 싶은 직원이 되어 사무실 천장에서 쏟아지는 물건을 받거나 피하는 **오리지널 브라우저 미니 게임**입니다.
TypeScript + Vite + HTML5 Canvas로 만들었고, 게임 로직은 렌더링과 분리된 순수 모듈이라 Vitest로 단위 테스트합니다.

## 기술 스택

- TypeScript
- Vite (개발 서버·빌드)
- HTML5 Canvas 2D (도형 + 이모지 그래픽)
- Vitest (단위 테스트)

## 폴더 구조

```
004_web_game/
├── index.html          # 캔버스 하나만 있는 HTML
├── src/
│   ├── game.ts         # 순수 게임 로직: 충돌 판정, 점수, 난이도, 상태 전이
│   ├── storage.ts      # 최고 점수 localStorage 저장/불러오기
│   ├── render.ts       # Canvas 렌더링(상태를 그리기만 함)
│   └── main.ts         # 입력(키보드·터치) 처리와 게임 루프
├── tests/
│   ├── game.test.ts    # 게임 로직 테스트
│   └── storage.test.ts # 최고 점수 저장 테스트
├── package.json
└── tsconfig.json
```

설계 포인트: `game.ts`는 DOM이나 `Math.random`에 직접 의존하지 않습니다.
`update(state, dt, input, random)`처럼 시간·입력·난수를 인자로 받아 **새 상태를 돌려주기만** 하므로 테스트에서 결과를 정확히 예측할 수 있습니다.

## 실행 방법

```bash
cd 000_sample_project/004_web_game
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm run build      # 타입 검사 + 프로덕션 빌드(dist/)
npm run preview    # 빌드 결과 미리보기 (http://localhost:4173)
```

## 테스트 방법

```bash
npm test
```

충돌 판정, 난이도 계산, 물건 종류 선택, 상태 전이(시작·일시정지·게임 오버·재시작), 점수/생명/커피 효과, 최고 점수 저장을 검사합니다.

## 조작법

| 동작 | 키보드 | 터치(모바일) |
| --- | --- | --- |
| 왼쪽/오른쪽 이동 | `←` / `→` | 화면 왼쪽/오른쪽 절반을 누르고 있기 |
| 시작·다시 시작 | `스페이스` | 화면 아무 곳이나 탭 |
| 일시정지·계속 | `스페이스` | 상단 점수판 탭(일시정지), 아무 곳이나 탭(계속) |

다른 탭으로 이동하면 자동으로 일시정지됩니다.

## 게임 규칙

- 📄 **결재 서류**: 받으면 +10점
- ☕ **커피**: 받으면 +5점, 5초 동안 이동 속도 1.6배
- 💣 **야근 폭탄**: 맞으면 생명 -1 (피해야 함)
- 생명은 3개이며 모두 잃으면 게임 오버("야근 확정...")
- 15초마다 레벨이 올라 물건이 더 빠르고 자주 떨어지며 폭탄 비율도 늘어납니다(최대 10레벨).
- 최고 점수는 브라우저 `localStorage`에 저장되어 새로고침해도 유지됩니다.
