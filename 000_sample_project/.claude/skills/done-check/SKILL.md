# 완료 점검

「다 했다」고 말하기 전에 아래를 순서대로 확인하고, 확인한 결과를 보고에 붙인다.

1. **요청과 결과 맞추기** — 처음 요청을 다시 읽고, 빠뜨린 항목이 없는지 하나씩 대조한다.
2. **실행해 보기** — 시험 명령(`CLAUDE.md` 1절)을 돌린다. 시험이 없으면 직접 실행해 결과를 본다.
3. **화면이 바뀌었으면 캡처** — 웹·앱 화면을 바꿨다면 실제 화면을 열어 확인한다.
4. **바뀐 파일 훑기** — `git diff --stat`으로 의도하지 않은 파일이 바뀌지 않았는지 본다.
5. **남은 문제 적기** — 못 한 것, 확인하지 못한 것, 일부러 미룬 것을 숨기지 않고 적는다.

## 보고 형식

- 한 줄 결과 : 무엇을 했고 확인했는지
- 증거 : 시험 결과 줄 수, 캡처, 만든 파일 경로 중 해당하는 것
- 남은 문제 : 없으면 「없음」
