# 웹툰 회차 기획 규격

사람이 준 시놉시스(장르·주제·결말)로 `episodes/epNN.json` 을 만든다. 그림은 그리지 않는다.
그림은 코드 그림이나 이미지 AI 가, 말풍선은 코드가 맡는다.

## 순서

1. **시놉시스 확인** : 장르, 주제, 결말, 회차 분량(컷 수)을 한 줄씩 정리해 사람에게 보여 준다. 빠진 것이 있으면 만들기 전에 묻는다(최대 3개).
2. **캐릭터 시트** : 인물마다 `name`, `name_en`(영어 이름, 선택), `desc`(한국어 외모 설명), `desc_en`(같은 내용의 영어), `look`(색 `#RRGGBB`, `hairStyle` short·long·bun, `glasses`).
   외모 설명은 이후 모든 컷에 글자 그대로 들어가므로 **짧고 구체적으로**(나이대, 머리, 안경, 옷 색) 쓴다.
3. **컷 나누기** : 컷마다 `id`, `height`(240~1600), `background`(office·night·monitor·plain), `gap_after`(다음 컷까지 여백 0~600px, 없으면 32), `scene`·`scene_en`, `cast`(인물·가로 위치 0.1~0.9·표정), `lines`(대사), 필요하면 `caption`. 아래 「연출 규칙」을 따른다.
4. **검증** : 아래 명령이 오류 없이 끝나야 완성이다. 오류가 나면 메시지의 경로(예: `panels[2].lines[0].who`)를 보고 고친다.

```bash
node src/cli.mjs episodes/epNN.json -o output/epNN --prompt-lang en
```

5. **콘티 확인** : `output/epNN/storyboard.md`(컷 / 연출 / 등장·표정 / 대사 / 프롬프트 표)를 사람에게 보여 주고 고칠 점을 받는다.

## 연출 규칙 (세로 스크롤 웹툰)

세로 웹툰은 독자가 **손가락으로 내리는 속도**가 곧 연출이다. 컷 높이와 컷 사이 여백으로 호흡을 만든다.

| 상황 | 컷 높이 | 다음 여백(`gap_after`) |
|---|---|---|
| 첫 컷(배경·상황 소개) | 크게 | 보통(24~48) |
| 빠르게 주고받는 대화 | 작게(400~520) | 좁게(0~24) |
| 반전·폭로 직전(독자가 멈칫하게) | 보통 | **넓게(120~240)** |
| 시간·장소가 바뀜(자막과 함께) | 보통 | **넓게(160~300)** |
| 감정이 터지는 큰 장면 | **크게(600~900)** | 보통 |

- **한 컷에 한 가지 일** : 한 컷에서 사건 하나, 감정 하나만 보여 준다. 말풍선은 한 컷에 3개까지.
- **반전은 다음 컷에** : 놀라는 얼굴(앞 컷) → 넓은 여백 → 놀란 이유(다음 컷) 순서로 둔다. 같은 컷에 넣으면 스크롤하기 전에 답이 보인다.
- **마지막 컷** : 연재물이면 다음 화가 궁금해지는 장면(새 인물 등장, 풀리지 않은 질문)으로 끝낸다(클리프행어). 단편이면 여운이 남는 장면으로 끝낸다.
- **같은 여백만 반복하지 않는다** : 모든 `gap_after` 가 같으면 호흡이 단조롭다. `storyboard.md` 의 「다음 여백」 열과 「전체 세로 길이」로 확인한다.

## 지킬 것

- 대사 하나는 60자까지. 길면 말풍선을 나눈다. 말하는 사람은 그 컷의 `cast` 에 있어야 한다.
- `style`·`style_en` 은 선 굵기·색감·분위기로 쓴다. **특정 작가·작품의 화풍이나 캐릭터를 흉내 내지 않는다**(검증에서도 막는다).
- 실존 인물·브랜드를 등장시키지 않는다.
- 이미지 AI 로 그릴 계획이면 그 서비스의 상업 이용 조건을 사람에게 확인하라고 알린다.

## 끝내기 전 점검

- [ ] 위 검증 명령이 「경고 0건」으로 끝났다
- [ ] 모든 인물에 `desc_en`, 모든 컷에 `scene_en` 이 있다
- [ ] 반전·시간 경과 앞에 넓은 여백이 있고, 마지막 컷이 연재면 다음 화로 이어지는 장면이다
- [ ] storyboard.md 를 사람에게 보여 줬다
