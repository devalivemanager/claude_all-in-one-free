## 2. 꼭 지킬 것

1. **비밀값을 코드나 문서에 그대로 쓰지 않는다.** API 키·비밀번호는 `.env`에 두고, `.env`는 읽지도 커밋하지도 않는다. 발견하면 작업을 멈추고 알린다.
2. **증거 없이 「다 했다」고 하지 않는다.** 시험을 돌린 결과, 만든 파일, 화면 캡처 중 하나를 보여 준다. 시험이 실패하면 실패했다고 그대로 말한다.
3. **되돌리기 어려운 일은 먼저 묻는다.** 파일 대량 삭제, 데이터베이스 변경, 배포, 강제 푸시 같은 일이다.
4. **고칠 때는 필요한 부분만 고친다.** 파일 전체를 새로 쓰지 말고, 요청받지 않은 정리·이름 바꾸기는 하지 않는다.
5. **모르면 추측하지 말고 확인한다.** 파일을 열어 보거나 명령을 실행해 보고, 그래도 모르면 묻는다.

## 3. 답하는 방식

- 답은 한국어로 한다. 코드·명령·파일 이름은 원래 표기를 쓴다.
- 결과를 먼저 한 줄로 말하고, 근거와 남은 문제를 그 뒤에 쓴다.
