# 02 초급 — 결과가 달라지는 지시 습관

> 같은 AI라도 지시하는 방식에 따라 결과가 크게 다르다. 아래 다섯 가지만 지켜도 다시 시키는 횟수가 확 준다.

## 1. 「끝난 상태」를 말한다

| 덜 좋은 지시 | 더 좋은 지시 |
|---|---|
| 로그인 기능 만들어 줘 | 이메일·비밀번호 로그인을 만들어 줘. 틀린 비밀번호면 「다시 확인해 주세요」를 보여 주고, `npm test`가 통과하면 끝이야 |
| 이 버그 고쳐 줘 | 빈 목록에서 「삭제」를 누르면 오류가 나. 재현 시험을 먼저 쓰고, 그 시험이 통과하게 고쳐 줘 |

「무엇이 되면 끝인가」를 말하면 클로드가 스스로 확인하고 멈출 수 있다.

## 2. 범위를 좁힌다

- 「이 파일만」, 「이 함수만」, 「화면은 건드리지 말고」처럼 손대도 되는 곳을 말한다.
- 문제가 생기면 「다시 해 줘」 대신 「여기가 이상해. 왜 이렇게 됐는지 이 부분만 보고 원인부터 말해 줘」라고 한다.

## 3. 큰 일은 나눈다

한 번에 「쇼핑몰 만들어 줘」보다 아래처럼 나누면 중간에 틀어져도 바로 잡을 수 있다.

1. 화면 목록과 데이터 구조를 정리해 줘(코드 쓰지 말고)
2. 상품 목록 화면만 만들어 줘
3. 장바구니만 만들어 줘
4. 결제 흐름은 계획 모드로 계획부터 보여 줘

## 4. 근거를 달라고 한다

- 「확실해?」라고 묻기보다 「어느 파일 몇 번째 줄을 보고 그렇게 판단했어?」라고 묻는다.
- 「됐어요」라는 답에는 「시험 결과를 보여 줘」, 「화면을 캡처해 줘」로 받는다.

## 5. 잘 된 지시는 남긴다

같은 지시를 세 번째 하고 있다면 그 지시는 **규칙이나 스킬이 될 자리**다.

- 늘 지켜야 하는 것 → `CLAUDE.md`(`03_초급_CLAUDE.md쓰는법.md`)
- 가끔 하는 정해진 절차 → 스킬(`04_중급_스킬·서브에이전트·MCP.md`)

## 바로 써 보는 지시 틀

```
목표 : [무엇을 만들거나 고칠지]
범위 : [손대도 되는 파일·폴더 / 건드리면 안 되는 곳]
끝 기준 : [어떤 시험·화면·출력이 나오면 끝인지]
모르면 : 추측하지 말고 먼저 물어봐
```
