# 06 중급 — 토큰과 비용 : 같은 일을 덜 쓰고 하기

> 클로드는 메시지를 보낼 때마다 **앞 대화 전체를 다시 읽는다.** 대화가 길수록 한 번 묻는 비용이 커지고, 엉뚱한 답도 늘어난다.

## 1. 가장 효과 큰 습관 세 가지

1. **주제가 바뀌면 `/clear`** — 앞 작업의 파일 내용과 대화가 더는 필요 없다.
2. **길어지면 `/compact`** — 같은 작업을 이어 가야 할 때 요약으로 줄인다.
3. **필요한 파일만 콕 집기** — 「프로젝트 전체를 봐」 대신 `@src/login.ts`처럼 짚는다.

## 2. 자주 새는 곳

| 새는 곳 | 줄이는 법 |
|---|---|
| 긴 CLAUDE.md | 늘 필요한 것만 남기고 나머지는 `docs/`로(`03_초급_CLAUDE.md쓰는법.md`) |
| 깔아 둔 스킬·MCP가 많음 | 설명이 매 세션 실린다. 안 쓰는 것은 끄거나 지운다 |
| 파일 전체 다시 쓰기 | 「바뀐 부분만 고쳐」라고 한다. 긴 파일을 통째로 다시 쓰면 출력이 끊겨 작업이 실패하기도 한다 |
| 긴 명령 출력 | 「마지막 20줄만」, 「오류 줄만」처럼 줄여서 보게 한다 |
| 작은 일에 서브에이전트 | 지시문 작성과 새 맥락이 비용이다. 파일 몇 개짜리는 직접 시킨다 |

## 3. 모델 고르기

- 설계·어려운 디버깅 → 큰 모델
- 정해진 형식 변환, 단순 반복 → 작은 모델
- `/model`로 바꾼다. 「무조건 제일 큰 모델」은 느리고 비싸며, 단순한 일에서는 차이가 작다.

## 4. 남은 양 보기

- `/context` : 지금 대화가 얼마나 찼는지
- `/cost` 또는 `/usage`(요금제에 따라 다름) : 쓴 양
