# 01 초급 — 첫 세션 열기와 꼭 알아야 할 명령

> 대상 : 클로드 코드를 설치했고, 이제 처음 써 보는 사람.
> 명령 이름은 바뀔 수 있으니 세션 안에서 `/help`로 확인한다.

## 1. 세션 열기

1. 터미널에서 프로젝트 폴더로 이동한다.
2. `claude`를 입력하면 세션이 열린다. 클로드는 이 폴더와 그 아래 파일만 다룬다고 생각하면 된다.
3. 처음이면 `/init`을 입력한다. 클로드가 폴더를 훑어보고 `CLAUDE.md` 초안을 만든다. 이 틀에는 이미 `CLAUDE.md`가 있으니 초안과 비교해 필요한 줄만 옮긴다.
   - 초안은 영어로 나오기도 하고, 비밀값 규칙이 빠지기도 한다(시험한 초안 40줄에 없었다). `03_초급_CLAUDE.md쓰는법.md`의 점검표로 손본다.

## 2. 첫 요청은 「읽기」로

처음부터 고치게 하지 말고 먼저 설명하게 한다.

```
이 프로젝트 구조를 설명해 줘. 실행 방법과 시험 방법도 찾아 줘.
```

설명이 맞는지 내가 확인하고, 틀린 부분은 `CLAUDE.md`에 바로 적는다. 이것이 규칙 파일을 키우는 가장 쉬운 방법이다.

확인하기 쉽게 「근거로 파일 이름과 줄 번호를 붙여 줘」를 덧붙인다. 줄 번호가 있으면 맞는지 바로 열어 볼 수 있다. 읽기만 시켰다면 시험은 돌려 보지 못했을 수 있으니, 보고에 그런 말이 있는지 본다.

## 3. 꼭 알아야 할 명령

| 명령 | 하는 일 | 언제 |
|---|---|---|
| `/help` | 명령 목록 | 모를 때 |
| `/clear` | 대화를 비우고 새로 시작 | 주제가 바뀔 때. 앞 대화가 길면 비용과 실수가 같이 늘어난다 |
| `/compact` | 지금까지 대화를 요약해 줄임 | 같은 주제를 이어 가는데 대화가 길어졌을 때 |
| `/context` | 지금 대화가 얼마나 찼는지 보기 | 응답이 느려지거나 엉뚱해질 때 |
| `/model` | 모델 바꾸기(다음 세션의 기본값으로도 저장된다) | 어려운 설계는 큰 모델, 단순 반복은 작은 모델 |
| `/permissions` | 허용·차단 규칙 보기 | 매번 묻는 것이 귀찮거나, 막아야 할 것이 있을 때 |
| `Esc` | 지금 하던 작업 멈추기 | 방향이 틀렸다고 느낄 때 바로 |
| `Esc` 두 번 | 입력 칸이 비어 있으면 앞 시점으로 되돌아가기(`/rewind`와 같음). 입력 칸에 글이 있으면 그 글을 지운다 | 지시를 잘못 했을 때 |
| `Shift+Tab` | 권한 모드 바꾸기(계획 모드 포함) | 큰 작업 전에 계획부터 받고 싶을 때 |
| `@파일이름` | 파일을 콕 집어 알려 주기 | 「이 파일을 봐」라고 할 때 |

## 4. 권한 묻기에 답하는 요령

클로드는 파일을 고치거나 명령을 실행하기 전에 묻는다.

- **처음 며칠은 매번 읽고 허락한다.** 무엇을 하려는지 배우는 시간이다.
- 안전하고 자주 쓰는 명령(예 : `git status`)은 「다시 묻지 않기」를 고른다.
- 지우기·배포·강제 푸시처럼 되돌리기 어려운 명령은 늘 묻게 둔다. 예시는 `.claude/settings.example.json`.

## 5. 계획 모드부터

파일 여러 개를 고치는 작업이면 `Shift+Tab`으로 계획 모드로 바꾸고 요청한다. 클로드가 고치지 않고 계획만 내놓는다. 계획을 읽고 고칠 점을 말한 뒤에 실행하게 하면 되돌릴 일이 크게 준다.

## 6. 첫 주에 자주 하는 실수

- 한 세션에서 주제를 계속 바꾼다 → 주제가 바뀌면 `/clear`
- 「알아서 잘」이라고만 한다 → 무엇이 끝난 상태인지 말한다(`02_초급_지시잘하기.md`)
- 결과를 확인하지 않고 넘어간다 → 실행해 보게 하고 결과를 보여 달라고 한다
- 잘못 고친 것을 말로 되돌리게 한다 → `Esc` 두 번이나 git으로 되돌린다. 작업 전에 커밋해 두면 안전하다
