# 주간 보고서 규격

## 구성
1. **한 줄 결론** : 이번 주에 가장 중요한 것 하나.
2. **수치** : 분류별 건수(`classification.counts`), 분류 실패 건수(`failures` 개수), 처리 실측값(`metrics`)을 표로.
3. **눈에 띄는 것** : 자주 나온 키워드와 맥락(`keywords`) 3개 이내.
4. **할 일** : 오류 제보·기능 문의에서 나온 다음 주 할 일. 담당과 기한을 칸으로 둔다(모르면 비워 둔다).

## 지킬 것
- 표의 숫자는 clean_data.json 값 그대로. 계산한 비율은 계산식을 함께 적는다.
- 분류 실패가 있으면 「분류 실패 N건은 사람이 다시 확인 필요」를 반드시 적는다.
- 개인을 알 수 있는 정보는 쓰지 않는다.

## 끝내기 전 점검
- [ ] 모든 숫자를 JSON 에서 찾을 수 있다
- [ ] 분류 실패 건수를 숨기지 않았다
