# 롱폼 시나리오 작성 규격

## 결과물
1. **소재 근거** : `keywords`(자주 나온 소재)와 `classification.counts`(반응 분포)를 2~3줄로 정리한다.
2. **줄거리** : 발단 → 전개 → 위기 → 절정 → 결말, 단계마다 2~3문장.
3. **대본** : 장면 번호, 장소·시간, 내레이션, 대사. 8~10분 분량(대략 2,000~2,600자)을 목표로 한다.
4. **쇼츠 연결 문구** : 롱폼으로 이어지는 쇼츠용 첫 문장 3개.

## 지킬 것
- 원문 요약(`summary.bullets`)은 줄거리의 재료로만 쓰고 문장을 그대로 옮기지 않는다. 새로 쓴다.
- 실존 인물·역사 사건을 다루면 사실과 각색을 구분해 표시한다(`[각색]`).
- 시청자 댓글을 그대로 인용하지 않는다.
- 다른 채널·작품의 고유한 캐릭터나 대사를 따라 하지 않는다.

## 끝내기 전 점검
- [ ] 소재 근거가 clean_data.json 의 값과 맞다
- [ ] 다섯 단계 줄거리와 장면별 대본이 있다
- [ ] 각색 표시가 빠지지 않았다
