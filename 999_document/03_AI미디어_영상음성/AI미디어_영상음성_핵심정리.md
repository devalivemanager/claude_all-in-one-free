# AI 미디어(영상·음성·음악·이미지) 핵심 정리

AI로 영상·목소리·노래·이미지를 만들어 보려는 사람을 위해, 유튜브 영상 31편을 보고 정리한 학습 노트를 주제별로 묶어 줄였다.
각 항목은 도구의 쓸모, 무료·상업 이용 조건, 따라 하기 전 주의점 위주로 적었고 출처 영상 링크를 남겼다.

> 근거 표시 : `[실측]` 직접 확인하거나 시험한 값, `[추측]` 정리하면서 짐작한 것, `[확인 못 함]` 원문·약관을 대조하지 못한 것. 수치·조건은 정리 시점(2026-10) 기준이며 바뀔 수 있다.

## 1. 영상 문법(도구와 무관한 기본기)

- **캐릭터 시트는 세 칸**이면 된다 : 전신 정면·전신 후면·얼굴 클로즈업. 한 장에 사람이 많으면 같은 얼굴이 여럿 나온다. 사람뿐 아니라 차·집·소품도 「캐릭터」로 고정해야 컷마다 바뀌지 않는다.
- **카메라 지시는 「움직임·속도·유지할 것·끝」 네 조각**으로 쓰고 장면 묘사와 분리한다. 가장 많이 빠뜨리는 것이 「끝」이다. 한 컷에 움직임은 하나만 둔다. 움직임·앵글·프레임 크기는 서로 다른 축이라 따로 정한다.
- **컷 길이는 설계다.** 30초를 통으로 뽑으면 내용이 7초여도 나머지를 AI가 지어낸다. 짧게 뽑으면 실패한 조각만 다시 만들면 된다. 10초 통짜보다 2~3초마다 앵글을 바꾸는 편이 덜 밋밋하다.
- **기준(앵커) 이미지 한 장**을 먼저 확정하고 나머지를 모두 그것을 참조해 뽑으면 색감·조명이 통일된다. 프롬프트에는 「~하지 마」 대신 있어야 할 것만 적는다. 바꿀 것과 유지할 것(얼굴·표정·입 모양)을 나눠 적는다.
- **소량 먼저 → 확인 → 확대.** 3편쯤 만들어 품질을 본 뒤 나머지를 만든다. 이미지 단계에서 충분히 확정하고 영상(크레딧이 가장 많이 드는 단계)으로 넘어간다.

## 2. 영상 생성·편집

### AI 숏드라마(제미나이 + 구글 Flow)
- 기획 : 잘되는 영상 **여러 개**를 제미나이에 넣어 갈등 시작·해소 시점, 좋아요 장치를 표로 뽑고 새 이야기를 만든다(하나만 넣으면 따라 하기로 끝난다).
- 대본에 만들 도구(Flow)를 명시하고 10초 단위로 맞춘다. 심의에 걸릴 장면(폭력)은 처음부터 각색한다. 영어로 넣으면 대사 언어가 엉뚱해지는 경우가 많아 장면·카메라·대사·효과·자막을 한국어로 나눠 쓴다.
- Flow 「캐릭터」 기능에 얼굴과 **목소리까지 저장**해 두면 이야기만 바꿔 같은 배우로 다음 편을 만든다. 에이전트 지시에 「캐릭터 그대로, 대사는 한국말로 분명하게, 2~3초마다 다른 앵글, 9:16」을 덧붙인다.
- 주의 : 「팔로워 1만 미만인데 150만 원 광고」는 화자 사례이고 증빙이 없다. 무료 크레딧이 작고 `[확인 못 함 : 현재 요금·한도]`, 무료 영상에는 SynthID 워터마크가 들어간다. 같은 틀로 찍어 내는 시리즈는 유튜브의 대량·반복 콘텐츠 수익 제한과 AI 생성물 표시를 의식한다.

### 구글 Flow 공학 쇼츠(브라우저 자동화)
- 클로드 코드가 크롬으로 Flow를 대신 눌러 이미지·클립을 뽑고, 한글 글자는 리모션, 나레이션은 로컬 음성으로 따로 만든다. 클립은 꼭 움직여야 할 자리에만 쓰고 나머지는 정지 이미지에 느린 카메라 이동을 건다. **장면표보다 나레이션을 먼저** 만든다(실제 음성 길이가 달라 다시 한 사례).
- 주의 : 구글 약관이 자동 조작을 허용하는지 `[확인 못 함]`이라 확인 전에는 따라 하지 않는다. 자동화용 크롬은 평소와 다른 포트·프로필로 띄운다. 제작자는 유료 구독자라 「완전 무료」는 아니다.

### LTX-2.5 요령
- 화면이 까맣게 나오면 가로·세로가 32의 배수인지, 프레임 수가 8의 배수 + 1인지 본다.
- 주의 : LTX-2.5는 매출 규모에 따라 상업 이용 조건이 갈리고(연 매출 1천만 달러 미만 무료) AI 생성 고지 의무가 있다고 영상이 설명한다. 실행은 로컬 그래픽카드에서 한다(무료 클라우드 GPU는 비상업 조항이 있는 곳이 많다).

### 잘 만든 영상을 샷 단위로 분석하기
- 클로드에 영상·촬영 감독 역할을 주고, 장면이 아니라 **카메라 컷이 바뀌는 샷 단위**로 샷 크기·구도·움직임·렌즈·조명·미술·편집을 분석시킨다. 「영상으로 확인할 수 없는 것(렌즈·장비)은 추정이라고 밝혀라」를 꼭 넣는다.
- 유료 생성 서비스 없이 무료로 할 수 있다 : ffmpeg 장면 전환 감지 `select='gt(scene,0.3)'`로 컷마다 대표 프레임을 뽑고, 클로드 코드가 이미지를 읽어 분석한다. 대사는 로컬 받아쓰기로 붙인다.
- 남의 영상은 구조만 배우는 교재로 쓴다. 영상 속 「남의 뮤직비디오 인물을 내 캐릭터로 바꾸기」는 저작권·초상권 문제가 커서 하지 않는다.

### 편집 보조(클로드)
- **숫자 카운트업·다운** : 「0에서 10까지 올라가는 SRT 파일 만들어 줘」 → 편집 프로그램에 얹고 속도를 올린다. 저장 확장자가 `.txt`가 아니라 `.srt`인지 확인한다. ffmpeg로도 같은 일을 할 수 있다.
- **형광펜 강조** : 이미지를 주고 OCR로 글자 위치를 잡아 효과를 렌더한다. **박스 모션 그래픽** : 리모션으로 만들어 투명 배경 MP4로 내보낸다.
- 수정은 「좀 더 크게」 대신 「글자 48px로」처럼 숫자로 요청한다. 시연의 영화 홍보 이미지처럼 남의 홍보물에 효과를 입히는 것은 피하고 직접 만든 이미지에만 쓴다.

## 3. 코드로 영상 만들기

생성형 영상 AI 없이 클로드가 코드로 그림·소리를 만드는 방식이다. 생성물 라이선스·워터마크 문제가 없는 대신 클로드 사용량이 크게 든다.

### 원리와 lemo-opuscar(MIT)
- 클로드가 쓰는 것은 영상이 아니라 **「시간 값을 받으면 그 순간을 그리는 웹페이지」**다. 화면 없는 크롬이 한 장씩 찍어 이어 붙인다. 전제는 Node.js·ffmpeg·파이썬과 클로드 구독(또는 종량제)이다. 소리도 코드로 만들고, 나레이션은 받아쓰기로 다시 들어 대본과 대조하며, 마지막에 유튜브 기준 -14 LUFS로 맞춘다.
- 자동 검사 규칙(직접 만드는 영상 점검표로 쓸 만하다) : 화면 행동마다 소리 하나, 진짜 침묵 두 번 이상, 열 자 묶음 글자 3.7초 안팎, 자막 최소 1.8초, 중요한 순간 주인공은 화면 높이 3분의 1 이상, 한두 초 간격 장면 뽑아 보기. 기획서에 이야기 구조 후보 3개를 먼저 쓴다.
- 결과 : 한 줄 요청(수채화 45초)에 24분 48초, 출력 토큰 약 93,000개(화자 발표). 원작급 그림은 반복 수정이 필요하다.
- 윈도우·한국어 막힘 : 파이썬 위치, 깃 배시 경로 자동 변환, 글꼴, 그리고 **받아쓰기 언어 자동 감지가 한국어를 중국어로 들은 일**(한국어 고정으로 해결). 음원·글꼴·음성 엔진 라이선스는 따로 확인한다.

출처 : 방구석컴퍼니 「클로드가 코드로 만든 아카데미 98편… 제 PC에서도 돌려봤습니다」 https://youtu.be/wMMl6blI_1U

### 60초 설명 영상 「프롬프트 한 장」
- 같은 주제로 세 방식을 비교했다 : 한 줄 지시는 화려하지만 숫자가 틀렸고, 사실 목록만 준 판은 숫자는 맞지만 60초 내내 같은 배치로 밋밋했으며, 사실 목록 + 연출 줄을 합친 판이 둘 다 잡았다. 밋밋함의 원인은 「장면마다 구도를 바꿔라」 같은 줄이 없어 가장 안전한 배치 하나로 버틴 것이다.
- 구조 8칸 : ① 주제 한 줄 ② **사실 목록**(화면 숫자는 여기서만, 쓰지 말 것 목록 포함) ③ 장면 흐름 4개 ④ 계산 줄(숫자는 실제로 계산) ⑤ 꾸밈 규칙(색 3·글꼴 2, 큰 글자 하나가 주인공) ⑥ 연출 줄(욕심 내기, 구도 바꾸기, 맞아떨어지는 순간 정지) ⑦ 기술 조건(크기·길이, **시간 결정론** : 아무 시각이나 다시 그려도 같은 화면) ⑧ 검사 줄(정지 화면을 뽑아 보고 고치기). 자기 판은 주제·사실 목록·장면 흐름 세 곳만 바꾼다.
- 흠은 처음부터 다시 돌리지 않고 **같은 대화에서 「이 세 군데만 고쳐 줘」** 한 번으로 고치고, 고치기 전후 같은 초를 나란히 놓고 확인한다.
- 비용 : 한 편 30분 가까이, 본 실행 + 수정이 API 환산 약 7.6달러어치라 수정 횟수 상한을 건다. 방식마다 한 번씩만 돌린 결과라 일반화는 조심한다. 배포 원문은 공개 글에 다시 싣지 않는다.

### 리모션(Remotion) 라이선스 `[실측 : LICENSE.md]`
- 무료 대상 : 개인, 직원 3명 이하 영리 회사, 비영리, 평가 목적. 무료 대상은 상업용 영상 제작도 무료다. 직원 4명 이상 영리 회사는 유료 회사 라이선스가 필요하다. 리모션 자체를 고쳐 되파는 것은 금지다.
- 5.0에서 라이선스가 바뀐다고 공지돼 있어 큰 버전을 올릴 때 다시 확인한다. 설치는 npm으로 수백 MB를 받는다.
- 쓰임 : 곡 제목 카드, 후렴 강조, 채널 인트로를 투명 배경 MP4로 뽑아 ffmpeg로 합성한다.

- 「확인해 줘」 같은 지시문은 반복해도 완벽히 지켜지지 않는다. 기준을 통과하지 못한 결과물은 **나갈 수 없게 만드는 장치**(테스트·훅)를 둔다. 「지시문은 확률을 낮추고 장치는 확정으로 막는다.」
- 순서 : 「무엇이 합격인가」와 **만들지 않을 것 목록**을 먼저 → 성공 기준을 프로젝트 안 파일에 두고 매번 읽게 → 기준을 테스트 코드로 → 발견한 문제는 테스트로 남겨 재발 방지.
- 첫 걸음은 「커밋할 때마다 검사가 돌게 해 줘」다. 검사는 내 컴퓨터가 돌려 AI 사용량이 들지 않는다. 장치를 걸었으면 **일부러 버그를 심어** 실제로 실패하는지 확인한다.
- 장치를 거는 기준은 **되돌릴 수 있느냐**다. 문구·화면 디테일은 맡기고, 핵심 계산·비밀 키·사용자 데이터·공개 발행·삭제·결제는 권한 설정·훅으로 막는다. 기준과 검사를 프로젝트 안에 두면 도구를 바꿔도 가져간다.
- 바로잡기 : 영상의 「보리스 체르니가 CLAUDE.md 지시문 80%를 지웠다」는 2차 자료에서 「시스템 프롬프트 80%」로 나와 대상이 바뀌어 전해졌을 가능성이 있다 `[원문 확인 못 함]`. 발언은 모두 화자를 거친 2차 정보다.

### 클로드 코드 입문 요점
- 최소 Pro 요금제가 필요하다. 새 기능은 계획 모드로 시작하고, 가장 단순한 반복 업무 하나부터 맡긴다. 에러를 고치면 워크플로 문서까지 갱신하고, 비밀값은 `.env`에 둔다. 스킬은 다 깔지 말고 하나씩, 설치 전에 내용과 라이선스를 읽는다.
- 토큰 절약 : 대화가 60~70% 찼을 때 「결정·미정·다음 할 일」을 파일에 남기고 `/clear`. CLAUDE.md는 200줄 이하, PDF·HTML은 마크다운으로 바꿔 넣는다. 자료는 raw(원자료)와 wiki(내 기준을 통과한 정리본)로 나눈다.
- 루틴(클라우드 예약 실행)은 저장소를 복제해 도니 공개해도 되는 작은 전용 저장소로 돌린다. 「외부 발송은 승인」 규칙에 걸려 멈춘 것은 규칙이 작동한 것이다.

### 개념·언어 지도
- 흐름 순서로 용어를 익히면 큰 그림이 잡힌다 : 도구(LLM·CLI·IDE) → 소스·깃 → 화면과 백엔드 → 서버(포트, localhost) → 배포(정적 페이지는 클라우드플레어 Pages·버셀) → 통신(HTTP·API·JSON) → 데이터(SQL). 비밀 키를 코드에 적지 않고 필요 없는 포트를 열지 않는 것은 따로 챙긴다.
- 언어 지도 : C(깊은 곳), 자바(은행·공공), 코틀린(안드로이드), 스위프트(아이폰), JS·타입스크립트(화면), Go(서버), SQL(DB), 파이썬(AI), C++(언리얼), C#(유니티), 러스트(안전한 고성능). 이제는 「쓰는 법」보다 **「알아보는 법」**이 중요하다. 틀렸을 때 「DB 쪽 같으니 SQL부터 확인해」라고 짚을 수 있어야 고치는 속도가 달라진다.
- 파이썬이 느린데 AI 표준인 이유 : 실제 행렬 계산은 아래층 C++·CUDA가 GPU에서 하고 파이썬은 지시만 한다. 연구 반복이 빨라 사람이 모였고 생태계(파이토치·허깅페이스 등)가 커져 표준이 됐다. 그래서 로컬 AI 도구가 GPU를 못 잡으면 파이썬 코드보다 아래층 라이브러리(CUDA·cuDNN) 설치를 먼저 의심한다.

## 11. 공통 교훈

1. **앱과 가중치의 라이선스는 따로 본다.** 앱이 MIT여도 모델 가중치가 비상업일 수 있고, 같은 모델도 저장소마다 조건이 어긋날 수 있다. 수익 용도라면 쓰기 직전에 원문을 다시 본다.
2. **수익 용도의 생성은 로컬에서 한다.** 무료 클라우드 GPU는 비상업 조항과 시간 한도가 있는 곳이 많다.
3. **일관성은 기준 하나에서 나온다.** 캐릭터 시트, 앵커 이미지, 사실 목록, 성공 기준 파일처럼 모든 결과가 참조할 기준을 먼저 확정한다.
4. **한글 글자·숫자는 생성 AI에 맡기지 않는다.** 배경만 생성하고 글자는 코드·HTML로 얹는다. 화면 숫자는 사실 목록에서만 가져온다.
5. **받아쓰기로 재검사한다.** 합성 나레이션·AI 노래는 로컬 받아쓰기로 다시 들어 대본·가사와 대조한다. 한국어는 언어를 고정한다.
6. **영어로 만든 도구는 한국어 표본으로 먼저 시험한다.** 에러 없이 결과만 틀어지는 경우가 많다.
7. **에이전트 권한은 좁게.** 「항상 허용」·「모든 권한 허용」·권한 우회 모드를 피하고, 원격 문서를 그대로 따르는 설치는 사람이 먼저 읽고 버전을 고정한다.
8. **남의 것은 구조만 배운다.** 잘된 영상·상세페이지·썸네일은 분석용으로만 쓰고 결과물은 새로 만든다. 남의 영상 인물 바꾸기, 실존 인물 목소리 복제, 가수 흉내는 하지 않는다.
9. **AI 생성물은 표시한다.** 유튜브 업로드 때 합성 콘텐츠 고지, 게임 출시 때 AI 사용 공개, 제휴·협찬 영상의 광고 표시를 챙긴다.
10. **수익 주장은 걸러 읽는다.** 증빙 없는 매출·광고 단가, 「10개 중 1개 성공」을 편집한 시연은 대략값으로만 본다.
