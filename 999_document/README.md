## 읽는 순서 추천

1. 처음이면 `01`의 「입문 : 용어·큰 그림」과 「클로드 코드 기본기」부터 읽는다.
2. 도구를 고를 때는 `04`를 먼저 본다. 무료여도 상업 이용이 안 되는 것이 꽤 있다.
3. 게임을 만들 생각이면 `02`를 처음부터 순서대로 읽는다(기획 → 엔진 → 제작 → 시험 → 출시).
4. 영상·음성 콘텐츠를 만들 생각이면 `03`의 한눈에 보기 표에서 필요한 절로 바로 간다.
5. 회사에서 ERP·SI 일을 한다면 `05`를 읽고, 같은 묶음의 `000_sample_project/docs`로 AI 작업 습관을 붙인다.

## 알아 둘 것

- 학습 정리본은 남의 영상·글을 우리말로 요약하고 따져 본 것이다. 원본의 권리는 원작자에게 있고, 자세한 내용은 각 항목의 원본 링크에서 본다.
- 「작성자 평가」, `[실측 : 작성자 …]` 표시는 정리한 사람이 직접 써 보거나 잰 결과다. 환경이 다르면 결과도 다를 수 있다.
- 법률·세무·라이선스 판정은 자문이 아니다. 중요한 결정 전에는 원문과 전문가에게 확인한다.
