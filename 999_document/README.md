## 알아 둘 것

- `[실측]` 표시는 작성자가 라이선스·약관 원문을 직접 열어 확인한 것이다. 요금·약관은 바뀌므로 쓰기 전에 원문에서 다시 확인한다.
- 법률·세무·라이선스 판정은 자문이 아니다. 중요한 결정 전에는 원문과 전문가에게 확인한다.
