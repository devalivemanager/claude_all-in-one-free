# 유튜브 → 스킬 (youtube-to-skill)

> 판 : v1.0 (2026-10-03) · 대상 : Claude Code · 무료 · 만든 곳 : 데브얼라이브 블로그 https://devalive.tistory.com
> 따라 하기 영상(튜토리얼) 하나를 **다시 쓸 수 있는 스킬(`SKILL.md`)** 로 바꾼다.
> **필요한 것** : Claude Code(서브에이전트를 부를 수 있는 환경), Python 3. 자막 자동 받기를 쓰려면 `yt-dlp`도. 폴더는 아무 곳에 두어도 되고, 명령은 이 폴더 안에서 실행한다.
> 이 폴더째 `~/.claude/skills/`에 복사해 두면 「이 영상 학습해 줘」 같은 말에 클로드가 `SKILL.md`의 순서를 스스로 따른다. 이 README는 사람이 처음 읽는 안내이고, 작업 절차는 `SKILL.md` 한 곳에만 있다.

## 들어 있는 것

| 파일 | 내용 |
|---|---|
| `01_원칙.md` | 왜 두 번 분석하는가 · 하지 말 것 · 저작권 |
| `02_지시문.md` | 붙여 쓰는 지시문 5개 — Ⓐ 첫 분석 → Ⓑ 독립 분석 → Ⓒ 병합 → Ⓓ 스킬 포장 → Ⓔ 실전 시험 |
| `templates/SKILL_template.md` | 스킬 파일 빈 틀 |
| `tools/yt_transcript.py` | 자막을 **시각이 붙은 글**로 정리하고 긴 영상은 구간으로 나눈다(읽기 전용 · 파이썬 표준 라이브러리) |

## 준비 — 두 갈래 중 하나

| 갈래 | 준비 | 자막 얻는 법 |
|---|---|---|
| **설치 없음** | 없음 | 유튜브 영상 아래 「…더보기 → 스크립트 표시」 → 전체 선택·복사 → `transcript.txt` 로 저장 |
| **자동** | `pip install yt-dlp` (무료 오픈소스) | `python tools/yt_transcript.py <영상주소>` 가 자막을 받아 정리. 언어는 `--lang ko,en` 순서로 **하나씩** 시도한다(한꺼번에 요청하면 유튜브가 429 로 거부한 일이 있다) |

## 쓰는 순서

영상 20분 기준 20~30분 걸린다. 단계(자막 준비 → Ⓐ 첫 분석 → Ⓑ 독립 분석 → Ⓒ 병합 → Ⓓ 스킬 포장 → Ⓔ 실전 시험)와 단계별 확인 방법은 `SKILL.md`의 「단계」 표에 있다. 클로드에게 시키지 않고 손으로 할 때는 `02_지시문.md`를 차례로 붙여 넣는다.

## 실전 시험 기록 `(2026-10-03)`

실제 영상 하나로 Ⓐ~Ⓔ 를 끝까지 돌렸다.

| 단계 | 결과 |
|---|---|
| 자막 받기 | ✅ 한국어 자동 자막 276줄(11분 45초) → 5분 구간 3개. ★처음엔 「ko,en 한꺼번에」 요청이 429 로 실패 → **언어를 하나씩 시도하도록 도구 수정** |
| Ⓐ Opus · Ⓑ Sonnet(새 컨텍스트, Ⓐ 비공개) | ✅ 10단계 · 12단계. ★Ⓑ 의 파일 쓰기가 환경 규칙으로 거부됨 → **텍스트로 받아 메인이 저장하도록 지시문 수정** |
| Ⓒ 병합 | ✅ 확정 10 · 보류→확정 5(전부 자막 원문 시각으로 확인) · 삭제 0 · 충돌 0 · 확인 필요 2. 명령 3개는 공식 문서(제3 출처)로 채움 |
| 지어내기 검사 | ✅ 두 분석 모두 자막에 없는 명령 철자를 **지어내지 않았다** |
| 정답 대조 | ✅ 영상 원본 배포물(README)의 사용법·주장과 단계가 일치 |
| Ⓔ 실전 | ✅ 실행 가능한 3단계(계량기·설정 확인·기간 비교)를 실제 기록에 돌려 증거 확보 · 앱 조작 단계는 「사람 조작 단계」로 구분 |

## 더 단단하게 (선택)

- **다른 회사 모델로 Ⓑ** — Gemini 무료 등급(구글 계정·API 키 필요, 하루 영상 8시간 분량)으로 Ⓑ 를 돌리면 같은 계열 모델끼리 겹치는 맹점까지 줄어든다
- **화면까지 봐야 하는 영상**(코드가 화면에만 나오는 경우) — 영상 보기 플러그인(`bradautomates/claude-video`, 오픈소스)이 필요하다. 자막만으로 되는지 먼저 본다
