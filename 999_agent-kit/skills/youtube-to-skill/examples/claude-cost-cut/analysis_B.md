## 핵심 주장
1. 4종 도구+내장 설정, 6과제×3=108회(윈도우, 빈 설정, 총 21.45$) — 10% 넘게 준 도구 없음. 발표 대 실측 : Caveman 65%↔−2%, Ponytail 20%↔+8%, RTK 60~90%↔+26%, Headroom 20%↔−3%. 통과 17~18/18
2. 두 자릿수는 생각 단계 낮춤뿐 : 비용 −15%, 출력 −32%, 18/18
3. 토큰 89~95% 가 캐시 읽기(1/10 단가, 과제당 약 32.8만 토큰), 말·코드는 비용 10~16%
4. Headroom 읽기 −36% → 비용 −3%(2.4센트). 외부 22과제 13개 더 비쌈(캐시 3번 깨짐, 계량기 −15.41$ ↔ 실제 +8.98$)
5. 작성자 청구 : 토큰 98% 재읽기 = 비용 69%. 결론 = 「몇 %」 말고 「어느 항목」

## 다루지 않은 것
1. 설치·실행 명령, 계량기 파일명·옵션 철자(화면 의존)
2. 맥·리눅스, 6과제 밖 작업, 반복 편차·통계적 유의성
3. 캐시 유지 시간별 요금제 차이, 계량기 출력 상세 해석법

(참고 : 자동 자막의 깨진 숫자 「7.6% 6%」·「8.5% 5%」는 값 불분명이라 제외)
