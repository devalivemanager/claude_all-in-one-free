# Claude Code 비용 줄이기 (실측 기반)

## 언제 쓰나

- 사용량 한도가 빨리 찬다 / 요금이 예상보다 많다
- 절약 도구를 깔까 말까 판단해야 한다

## 범위 밖

- 절약 도구 설치·설정(필요하면 각 도구 문서를 따로 본다)
- 모델 단가 협상·요금제 변경

## 단계

| # | 할 일 | 됐는지 확인하는 법 |
|---|---|---|
| 1 | 토큰 계량기로 최근 기록을 잰다 — 입력·캐시 쓰기·캐시 읽기·출력 네 줄의 **비용 비중** | 네 줄의 비용 % 가 나왔다 |
| 2 | 생각 단계(effort)를 **낮음**으로 — 계속 쓸 설정이면 저장, 이번 대화만이면 일회 적용 (명령 이름 : 「확인 필요」 — 설정 파일의 `effortLevel` 로도 가능) | 다음 대화에서도 낮음이 유지된다 |
| 3 | 생각 단계는 **대화 시작 때** 정한다 — 도중에 바꾸면 캐시가 한 번 깨진다 | 대화 도중 변경 없음 |
| 4 | 새 일을 시작할 때는 `/compact` 대신 `/clear` — 요약은 대화 전체를 읽는 유료 요청 | 무관한 작업 전에 비웠다 |
| 5 | 다시 볼 대화는 `/rename` 으로 이름을 붙인다 | 이름으로 다시 찾을 수 있다 |
| 6 | 캐시를 깨지 않는다 — 1시간 넘게 쉬었으면 새 대화, 도중에 첫 지시문·도구 목록·생각 단계 변경 금지, 이미지 넣고 빼기 주의 | 사용량 화면의 캐시 놓침 이유가 줄었다 |
| 7 | 사용량 화면에서 캐시 줄(적중 비율·놓친 횟수·이유)을 본다 (화면 이름 : 「확인 필요」) | 놓친 이유가 보인다 |
| 8 | 도구를 켰다면 켜기 전·후 기간을 계량기로 비교한다 — 일한 양이 다르면 응답 1건당으로 | 전후 비용 차이가 숫자로 나왔다 |
| 9 | 도구는 「몇 % 절감」 안내가 아니라 **청구서 어느 줄**을 건드리는지로 고른다. 도구가 스스로 찍는 절감 숫자는 근거가 아니다 | 켠 도구마다 건드리는 줄과 그 줄의 비용 비중을 안다 |

## 참고 수치 (영상 실측 · 소넷 · 작은 저장소 · 108회)

- 생각 단계 낮춤 : 비용 −15%, 과제 18/18 통과 — **두 자릿수는 이것 하나**
- 절약 도구 4종 : −3% ~ +26%(증가 포함). 출력을 줄이는 도구는 출력 줄(비용의 10~16%)만 건드린다
- 캐시 읽기 : 토큰의 89~98%, 단가는 입력의 1/10

## 막히면

- 같은 단계가 두 번 실패하면 멈추고 무엇이 막혔는지 보고한다
