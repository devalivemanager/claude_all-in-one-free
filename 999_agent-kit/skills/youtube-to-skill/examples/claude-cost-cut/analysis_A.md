## 영상의 핵심 주장(수치)

- 절약 도구 4종 × 과제 6개 × 3회 = 108회. 10% 넘게 줄인 도구 없음, 둘은 오히려 +8%(Ponytail)·+26%(RTK). 생각 단계 낮춤만 −15%(출력 −32%, 18/18 통과) — 00:07~00:19, 01:36~02:33
- 토큰의 89~95% 가 캐시 읽기(단가 1/10), 말·코드(출력)는 비용의 10~16% — 02:38~03:09
- Caveman 출력 −23% → 비용 −2% · Headroom 읽기 −36% → 비용 −3% — 03:11~03:50
- Headroom 외부 사례 : 22개 중 13개가 더 비쌈 — 캐시가 깨져 600만 토큰이 제값으로 — 07:15~07:51
- 작성자 7일 기록 : 토큰 98% 가 캐시 읽기, 비용 69%. 출력은 토큰 0% · 비용 11% — 10:17~10:29
