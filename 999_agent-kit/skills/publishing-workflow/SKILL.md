# 블로그·전자책 원고 작성과 발행 점검

> 근거 : 작성자가 블로그 연재 13편을 실제로 쓰고 올리며 다듬은 절차다. 원고 점검·발행 자동화 도구는 이 묶음에 들어 있지 않다. 아래에서 「점검 도구」·「발행 도구」는 자기가 쓰는 도구(또는 손 점검)로 바꿔 읽는다. 발행을 자동화하려면 블로그 서비스 약관(자동화 수단 이용 조항)부터 확인한다

## 언제 쓰나 / 범위 밖

- 쓴다 : 연재 글 한 편을 쓰고 올릴 때, 지난 글을 고칠 때, 연재를 전자책으로 묶을 때
- 범위 밖 : 남의 글을 번역해 옮기기(하지 않는다), 로그인·결제(사람이 직접)

## 1. 쓰기 전

| 할 일 | 됐는지 확인 |
|---|---|
| **한 줄 요지 → 절 제목 4~6개 → 맺음 다섯 줄**을 먼저 적는다(계획형) | 요지 한 줄에 안 들어가는 내용은 다음 편으로 보냈다 |
| **한 편에 핵심 하나** | 제목만 보고 무슨 글인지 안다 |
| 완성 기준 : 분량(본문 약 2,000~3,000자), 표 1개 이하, **실제로 한 일** 최소 하나 | |
| 보관 파일(`darlings.md`)부터 훑는다. 지난번에 뺀 문단·글감이 들어 있다 | 두 번 이상 빠진 이야기는 한 편 감이다 |

## 2. 쓰는 동안

- **첫 문단은 실제로 한 일**로 연다. 「개발자 여러분」 같은 대상 부르기, 「끝까지 보시면」, 막연한 전제는 뺀다
- 확인이 필요한 숫자·날짜는 `[확인]`을 붙여 두고 흐름을 끊지 않는다 → 발행 전 0개
- 절 제목이 곧 주장이 되게 쓴다(「충돌은 생각보다 적었습니다」)
- 줄일 때 아까운 문단은 지우지 말고 `darlings.md`로 옮긴다
- **제목의 핵심어는 연재 번호 바로 뒤**에 둔다(검색 결과에서 뒤쪽이 잘린다)

## 3. 발행 전 점검 : 「사실과 저작권 점검」

보고에 이 절을 따로 둔다.

| 항목 | 확인 |
|---|---|
| 사실 | 문장마다 실제 기록(작업 로그·설정·메모)과 대조. 추측한 원인은 줄이거나 「추측」으로 표시 |
| 숫자 | 근거 없는 수치 제목(「200%」, 「3시간 절약」) 금지. 실측한 숫자만 |
| 고유 정보 | 회사·고객사·제품명·실제 경로·계정·포트·내부 코드 → 가상 이름 또는 일반 표현. 캡처는 가린다 |
| 저작권 | 공식 문서·남의 글은 번역해 옮기지 않고 **자기 말로 + 출처**. 인용은 짧게 한두 구절. 이미지는 직접 만든 것이나 라이선스 확인된 것 |
| 상표 | 남의 제품명은 이름으로만. 로고 쓰지 않음, 「공식」 표현 금지. 블로그·판권 면에 「○○와 관련이 없습니다. ○○는 ○○의 상표입니다」 한 줄 |
| 남 비판 | 도구·제작자에게 나쁜 의도가 있었던 것처럼 읽히지 않게(「몰래」 → 「묻지 않고」) |

- 원고 기계 점검 : 금지어·엠대시·태그 줄처럼 기계가 셀 수 있는 것은 점검 스크립트로 만들어 매번 돌린다(같은 지적이 두 번 나오면 규칙·자동 검사로 올린다)
- 사람이 고친 문장은 판정 기록 파일에 쌓아 둔다. 나중에 교정 도구를 만들 때 시험 세트가 된다

## 4. 발행

1. 공개 발행은 **매번 사람 확인**을 받는다. 로그인은 사람이 직접 한다
2. 발행을 도구로 할 때는 도구가 「빈 결과」를 돌려주면 성공이 아니라 「실행 안 됨」으로 본다
3. 편집기를 스크립트로 채울 때 `setContent`로 넣으면 저장되지 않는 경우가 있다(티스토리 편집기에서 겪음) → 본문을 클릭한 뒤 `mceInsertContent`로 넣는다
4. 발행 뒤 : 공개 주소가 열리는지(HTTP 200) → **직전 편의 「다음 편」 링크**와 연재 목록 갱신 → 글 목록 파일에 추가 → 공개 화면 전체 점검 「걸린 항목 0」
5. **하루 한 편**. 남는 재료는 `darlings.md`로

## 5. 전자책으로 묶기

- 원고 정본은 마크다운 파일 하나씩. 묶을 때만 EPUB로 변환한다(pandoc, 작가용 도구 등 후보를 결과물로 비교)
- 판권 면 : 상표 고지 + 「집필 시점 기준이며 바뀔 수 있다」 + 후원·인증 없음
- 블로그 글을 그대로 붙이지 말고, 보관 파일의 빠진 문단으로 보충한다

## 끝나는 조건

「사실과 저작권 점검」 절이 보고에 있고, 공개 화면 점검이 「걸린 항목 0」이며, 직전 편 링크가 갱신됐다.
